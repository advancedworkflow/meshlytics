# @meshlytics/react-router

**Planned, not implemented yet.**

This adapter will wire Meshlytics pageview tracking into React Router's
`useLocation` hook, the same way `@meshlytics/next` does for the Next.js
App Router. Tracked in the main repo roadmap — see the root [README](../../../README.md#supported-frameworks).

Contributions welcome: open an issue before starting work so the API
shape can be agreed on first.
